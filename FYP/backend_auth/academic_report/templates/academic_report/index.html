Upload Assessment Data

Provide an Excel file (.xlsx) containing student grade letters. The file should include columns for Quizzes (1-4), Assignments (1-4), Mid Term Questions (Q1-Q4), and Final Term Questions (Q1-Q4). Cells should contain grade letters (A+, A, A-, B+, B, B-, C+, C, C-, F).

How It Works

The system reads your Excel file containing grade letters per assessment and calculates:

  • Grade Distribution: Counts of A+, A, A-, B+, B, B-, C+, C, C- per assessment
  • OBE_EEMU: 4-level OBE vector (Excellent, Effective, Minimal, Unsatisfactory)
  • CLO Averages: GPA-weighted averages per Course Learning Outcome
  • EPAN: Overall average across all CLOs

The report generates Program Outcomes mapping, Head Wise Grade tables, and OBE_EEMU measurements.
